# Security Policy

## Supported versions

Security fixes are applied to the latest release on `main`.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's private vulnerability reporting for this repository, or contact the Luminary Lane maintainers through the repository's security advisory flow. Include reproduction steps, impact, and any suggested mitigation.

We will acknowledge reports promptly, investigate privately, and coordinate a fix and disclosure where appropriate.
